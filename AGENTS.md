# Build and runtime

.local.json is ignored and maps runtimeRoot to the separate local runtime/toolchain workspace. Resolve it through outputs/Runtime-Paths.ps1 rather than assuming everything lives in the repository. Build with PowerShell 7:

- .\Build-Bridge.ps1 -Target minecraft
- .\Build-Bridge.ps1 -Target gd

The wrapper uses the cached JDK17/Gradle/Fabric and native Geode/MSVC toolchains. Read build.gradle and mod.json for staged versions; install receipts and hashes determine what is actually running. Build and installation are separate operations. Preserve the installed package while preparing a new stage.

Use canonical .\outputs\Control-Bridge.ps1 -Action <action> -PayloadJson '<json>' for background native commands. The root Control.ps1 delegates to this canonical script. Runtime status, exported blueprints, worlds, music and recordings live under runtimeRoot/outputs. Prefer native commands and Minecraft framebuffer recording; do not focus, capture or drive the desktop unless required for the task. A control acknowledgment proves receipt, not completion of queued world work. Server world jobs stop while Minecraft is paused; the explicit resume-world command supports only closing its pause menu and must not dismiss unrelated screens.

# Coordinate and verification rules

30 GD units equal one Minecraft block. An ordinary full cell (x,y,0) compiles to native center ((x+.5)*30,(y+.5-64)*30); compound pieces retain their fractional local offsets instead. Serialized GD editor Y is native world Y minus90. Native collision AABBs already include transforms: do not scale or rotate them twice. The active GameplayRegion and export manifest define the edited bounds. Preserve original nonphysical records and physical continuation outside both edited X and Y bounds. Reject malformed ranges rather than silently expanding or resetting them.

Run the appropriate cached build and inspect the resulting package/version/hash. Verify behavior with fresh native telemetry, actual exported server-cell manifests/blueprints, and native framebuffer frames or timestamped recordings. Use docs/world-authority-move.json as the established test pattern:2714 exported cells matched native centers, and moving stone(29,72,0) to(30,72,0) removed the old collider and moved the new one by30 GD units. Transition evidence is in docs/gd042-runtime-transition.json. These checks do not prove an unchanged XO course or normal full completion. Noclip output is visual QA only and must stay labelled as such.

Do not present generated concepts, synthetic overlays or a successful compile as live gameplay evidence. State unverified behavior plainly. Existing tests do not establish exhaustive trigger, special-object or effect support. Current limitations include incomplete particle/effect export, unsupported stairs/slabs and other non-full shapes, reserved vanilla special-marker materials, and native implicit floor/ceiling authority. The current MC0.4.3 source protects owned Z0 from streaming terrain generation when scene, world-authority or editor ownership is active. Preserve this guard and verify removed blocks remain absent through streaming and restart; the native implicit floor/ceiling issue remains separate and unresolved. The SDK does not yet establish a safe Windows implicit-plane override or verified serialization of nonuniform scale keys128/129.

Keep game binaries, licensed game textures/assets, downloaded levels, saves/worlds, toolchains, compiled packages, recordings, secrets and local runtime configuration out of Git. Follow .gitignore; never force-add ignored runtime material. The selected generated art reference is the documented exception. Keep source, reproducible tooling, small verification metadata and honest documentation reviewable for the next push.
