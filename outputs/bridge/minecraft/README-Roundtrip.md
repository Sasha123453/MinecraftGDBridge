# Minecraft → Geometry Dash: MC 0.3.8 / GD 0.4.0

Команды запуска, импорта, музыки и записи: outputs/README.txt. Текущие пакеты установлены 2026-10-03 11:31:56; хеши и резервная копия в outputs/visual-batch-install.json. Native 2D artwork — режим по умолчанию. Экспериментальные объёмные тела выключены; их визуальное соответствие образцу не подтверждено.

Import-GDLevel.ps1 оставляет полный исходный native GD-уровень активным, импортирует маркеры первой области и возвращает play-mode без F6. Серверные маркеры остаются для редактирования, клиент скрывает их во время игры. Auto XO 58835426 проверен на первых 20 секундах: ноль смертей, noclip выключен. Полное прохождение ещё не подтверждено.

1. F7 включает Creative и отдельную паузу GD. Плоскость z=0, x=0..512, y=67..100; пол Y66.
2. Полные блоки задают solids; magma/iron bars — spike; специальные маркеры представляют поддерживаемые orb/portal types. Импорт сохраняет native записи и смещения объектов, привязанные к маркеру.
3. F6 экспортирует до20000 объектов во временный вариант. Продолжение за X-окном и нефизические записи сохраняются. Физические записи внутри окна заменяются маркерами; объекты вне поддерживаемого Y внутри того же окна могут потеряться. Полная XO длиннее512 Minecraft-блоков: F6 не является полной конвертацией без потерь.
4. Space / Up / левая кнопка мыши управляют native GD; R — restart. Меню Minecraft отдельно удерживает simulation и FMOD. Закрытие меню не снимает паузу редактора.

Масштаб:30 GD units=1 блок. Центр маркера (x,y,0) соответствует ((x+0.5)*30,(y+0.5-64)*30) в GD. GD остаётся источником физики и collision shapes; native artwork использует его UV, RGBA и blend factors.

Источники: xo-auto-popular-source.json — Auto58835426; xo-easy-jukaras-source.json — ручной Easy58898913. Источник JSON <=64MiB, compressed levelString <=4MiB, распакованный уровень <=20MiB. Публичные варианты не подтверждены как точная карта видео Nasgubb. Пользовательские сохранённые GD-уровни не перезаписываются.

Мир: outputs/launcher/data/instances/gdbridge/.minecraft/saves/GDBridge-XO. Перед первым редактированием создаётся GDBridge-XO-before-authoring. Декоративные сцены cave/library/Nether/forest применяются отдельно. Cave-height expansion после основного плана поднимает крышу до Y89..90; terrainFloor ограничен Y<=66 и не затрагивает авторские маркеры Y67+. В обычных scenery boxes z=0 запрещён.

Native framebuffer recorder: fps1..20, длительность1..20 секунд, до400 PNG. Явный resumeForRecording временно закрывает только GameMenuScreen и возвращает его, если пользователь не сменил экран/мир. Рабочий стол, фокус и ввод ОС не используются. В MP4 сохраняются фактические интервалы кадров.
